# IR1 单通道 · 按台风年份 8:2 · 五臂缺测处理对照 —— 最终报告

> 实验日期：2026-10-12 至 10-13
> 口径：IR1 单通道（in_channels=1）、vgg16、by_year 时序 holdout（训练 2003–2013 = 15952 帧 / 测试 2014–2016 = 4107 帧，20.5%）、无验证集、**测全集**（damage_filter 全关）、80 轮、bs64、AMP、seed 42（单次）
> 一致性：五臂共用同一 config（`configs/tcir_wpac_ir1_year.yaml`），同一测试集，逐帧配对可比。
> **a5（2026-10-13 追加）**：把 U-Net 学习式修复做进**训练与测试的输入侧**（离线预修复缓存），
> 完整报告见 `docs/a5_unet_train_report.md`。

## 3. 五个结论

### 结论 1：修复与否是决定性的；修复方式之间差异极小（a2 与 a5 几乎等价）

a1（不修复）→ a2（griddata）/ a5（U-Net）把全集 RMSE 从 12.714 降到 12.521 / 12.466，
损坏帧从 13.499 降到 12.731 / 12.654。**收益量级 0.2–0.85 kn**。

但 **a2 vs a5 只差 0.05–0.08 kn（0.4–0.6%）**，配对检验 p=0.82（详见 `docs/a5_unet_train_report.md`）。
换句话说：**"要不要修复"重要，"用什么修复"不重要**。全集收益之所以温和（−0.19 ~ −0.25），
是因为测试集里损坏帧只占 12.6%（519/4107），且本次是**时序外推**（测试年份 2014–2016 训练中完全没见过），
比随机划分更严。

**关键看损坏帧组内**：a2/a5 把损坏帧偏置从 −1.27 修到 −0.11 / −0.37——插值/f修复真正干的事，
是**消除缺测帧的系统性低估**，而不是普遍提升。

### 结论 2：仅干净图训练（a3）是最差方案，损坏帧彻底崩盘

a3 全集 RMSE 13.272（最差），且损坏帧 RMSE **17.075**、R² 掉到 0.70——比 a1 差 3.6 kn。原因直白：
模型只见过干净图，遇到带条状缺测的输入直接分布外（OOD），而且**偏置 −2.96 说明它把损坏帧当成更弱的风暴来报**
（缺测条带被当成弱信号）。

这个结论对后续使用者非常直接：**不要指望"训练时避开脏数据"能解决问题，缺测是测试时一定会遇到的，必须在训练时见过**。

### 结论 3：条状增广（a4）几乎追平修复方案，是免修正的最佳选择

a4 全集 12.657，比 a2 只差 0.14 kn、比 a5 差 0.19。损坏帧上：RMSE a4 = 12.780 vs a2 = 12.731 / a5 = 12.654
（接近），**偏置 a4 = +0.18（接近零）**。

也就是说，**用真实检测到的条状掩码做增广，能达到和逐帧插值/修复几乎相同的"抗缺测"效果**，
而训练成本几乎为零（不用跑插值或修复管线）。**对 IR1 条状缺测，"训练时贴真实掩码"是"逐帧修复"的平替**。

### 结论 4：所有方案的"干净帧"性能几乎相同（12.44–12.64）

干净帧上五臂 RMSE 差距 ≤0.20 kn（其中 a1–a4 差距 ≤0.14）。这说明：

1. **缺测处理方案的选择只影响损坏帧**（12.65→17.08 的巨大差异），对干净帧几乎零影响
2. a4 增广没有伤害干净帧性能（12.639 vs a1 12.596，差 0.04）——增广是"免费午餐"
3. 单通道 IR1 的性能天花板约在 12.4–12.5（by_year 严格外推下）

### 结论 5：U-Net 修复输入（a5）是五臂最优，但优势不显著

a5 在全集/干净/损坏三个口径上全部最优（12.466 / 12.438 / 12.654），比 a2 好 0.05–0.08 kn。
值得注意的是 **a5 连干净帧也最好**——干净帧各臂输入完全相同，差异只能来自训练集：
a5 训练集里损坏帧被 U-Net 修复得更接近真实干净图，模型学到更一致的特征。

**但**：0.05–0.08 kn 远小于单 seed 噪声，配对检验 p=0.82，**不能据此断言 U-Net 更优**。
这与推理级结论（`docs/a3_repair_compare.md`，p=0.34）一致：**U-Net 的像素级优势（缺测区 RMSE −20%）
不会传导到下游强度回归**。

## 4. 实用建议（给后续使用者）

1. **必须修复/防缺测**（a1 或 a3 都不可取）；**要上生产首选 a2（griddata）**——零成本、无模型依赖、
   无需预生成缓存，下游与 U-Net 等价
2. **a4（条状增广）是免修正的平替**——不想在推理时跑修复管线就用它，效果几乎一样
3. **a5（U-Net 修复输入）仅在"大面积损坏"（>8% 档）有微弱优势**（12.216 vs 12.822），
   可按检测到的缺测面积触发；但整条流水线更重，收益不显著
4. **绝不要用 a3（仅干净图训练）**——损坏帧 RMSE 17.1、偏置 −2.96，会系统性低估带缺测的台风
5. **报告时必须分"干净/损坏"两组**——全集 RMSE 会稀释损坏帧的差异（12.6% 的帧贡献了大部分分化）
6. 所有修复方案都把损坏帧**偏置大幅归零**——共同作用机制是"让模型在训练时见过 / 不被缺测误导"，
   而不是"补全像素值"

## 6. 注意事项

- **单次实验**（seed 42 only）。臂间排序结论可靠（差异明显：a3 崩盘 / 其余接近），
  但 a2 vs a4 vs a5 的 0.05–0.15 kn 差距在单 seed 下不宜过度解读
- 测试集（2014–2016）的风暴分布与训练年（2003–2013）可能有强度分布差异，属时序外推的固有属性
- by_year 比之前的 by_storm 更严格（测试年份完全未见过），因此绝对数字与 v2 口径（by_storm、3 通道）不可直接比较
- a5 用的是**新 U-Net（areamatch 版）**；`docs/a3_repair_compare.md` 的 unet 变体用的是**旧 U-Net**
