# U-Net 图像修复（IR1 条状缺测）实验报告

> 任务：用「干净 IR1 图 + 真实条状缺测掩码」合成人工损坏图，训练「损坏 → 修正」的 U-Net，
> 并与项目既有的 `griddata` 空间插值基线比较补全质量。
> 日期：2026-10-13 ｜ 代码：`tcintens/models/unet.py`、`scripts/{build_inpaint_pairs,train_inpaint_unet,eval_inpaint_unet}.py`

---

## 1. 结论速览

**在缺测区域内，U-Net 显著且稳定地优于 griddata 插值。**

| 指标（亮温 K，越低越好） | griddata | U-Net | 改善 | U-Net 胜率 | 配对 t 检验 |
|---|---|---|---|---|---|
| **缺测区 RMSE** | 9.231 | **7.369** | **+1.861（−20.2%）** | **97.0%** | t=15.61, p=4.9e−45 |
| **缺测区 MAE** | 6.189 | **4.800** | **+1.389（−22.4%）** | **98.8%** | t=15.59, p=6.5e−45 |
| 全图 RMSE | 2.822 | **2.427** | +0.395（−14.0%） | 88.8% | t=7.97, p=1.1e−14 |
| 全图 MAE | **0.607** | 0.819 | −0.212（+34.8%） | 10.2% | t=−20.65 |

- 评估集：**测试年（2014–2016）干净帧**抽样 **N=500**，逐样本配对（同一张图同一掩码两种方法）。
- 「胜率」= U-Net 在该指标上优于 griddata 的样本比例。
- ⚠️ **全图 MAE 上 griddata 更好是"构造性"的，不是真实质量差距**：griddata 只改缺测像素、掩码外像素误差恒为 0，
  故其全图 MAE ≈ 缺测区 MAE × 缺测面积占比（6.189 × 0.101 ≈ 0.62，与实测 0.607 吻合）；
  U-Net 会轻微扰动整幅图，在掩码外引入小误差。**评价修复质量应看缺测区指标**（差 20%+）。

### 按缺测面积分档（缺测区 RMSE）

| 面积档 | n | griddata | U-Net | 改善 | 胜率 |
|---|---|---|---|---|---|
| 5–7.5% | 199 | 9.393 | **7.507** | +1.886 | 96.0% |
| 7.5–12.5% | 200 | 9.067 | **7.262** | +1.805 | 98.5% |
| 12.5–20% | 74 | 9.250 | **7.199** | +2.050 | 95.9% |
| >20% | 27 | 9.187 | **7.613** | +1.574 | 96.3% |

**改善幅度对缺测面积不敏感**（+1.57 ~ +2.05 K），即 U-Net 在各个面积档都稳定领先，
不存在"只对小面积有效"或"大面积就失效"的问题。

### 极端个例

- **U-Net 大胜（差距 >15 K）**：idx 17926（面积 15.6%，28.93 → 12.63）、16592（6.2%，23.68 → 7.57）、
  16827（6.2%，25.00 → 9.06）、16017（10.7%，22.65 → 7.05）、16515（6.3%，22.56 → 7.32）。
  ⇒ 这些都是 **griddata 插值彻底失效**（误差 22–29 K）而 U-Net 能救回来的场景，机制与
  `docs/inpaint_improvement.md` 的结论一致：**插值在"缺测切断强梯度（贴近风暴眼墙/对流核心）"时会崩**，
  而 U-Net 学到了 IR1 的空间结构先验，能重建梯度。
- **U-Net 落败**：5 例差距仅 −0.17 ~ −1.34 K，且都发生在 griddata 本身就很好（5.3–11.2 K）的样本上。
  即 U-Net 的少数失败是"锦上没添花"，而非"把好的弄坏"。

## 2. 数据与协议

| 项 | 设定 |
|---|---|
| 图像 | IR1 单通道，96×96，归一化 `(x−260.864)/32.849` |
| 干净帧 | `scan_damage(nd==0)`：训练年 **12502** 张、测试年 **3588** 张 |
| 掩码 | `logs/ir1_strip_masks.npz` 中面积 **5%–40%** 的 **1155** 个真实条状掩码（中位 8.05%） |
| 划分 | **训 2003–2013 / 测 2014–2016**（严格时序外推，与四臂实验同口径，无年份泄漏） |
| 合成 | 在线：每个 epoch 随机「干净帧 × 掩码」，随机水平镜像 + 纵向平移 ±24 px；掩码处置哨兵（归一化 −7.94） |

- 掩码库**只从训练年检测**，刻意不碰测试年的真实损伤形态，避免另一种泄漏。
- 评估用的掩码也从同一库抽（因为测试年"干净帧"上本无缺测，必须人工造损伤才能算 RMSE）。

## 3. 模型与训练

| 项 | 设定 |
|---|---|
| 结构 | U-Net，4 次下采样，base=48，**17.46 M 参数** |
| 输入 / 输出 | 2 通道（损坏图 + 0/1 掩码） / 1 通道（修复图，线性输出无激活） |
| 损失 | L1，缺测区域 **4× 加权**（`loss = full_l1 + 3·roi_l1`） |
| 优化 | AdamW lr 1e-3、wd 1e-4、CosineAnnealing、梯度裁剪 1.0、AMP |
| 轮数 | 60 轮，bs64，~33 s/轮（12502 帧） |
| 产物 | `outputs/tcir_inpaint_unet/`（`best.ckpt` best_roi=0.1452 @ epoch 57） |

**给掩码通道是关键设计**：网络无需自己推断"哪里坏了"，只需专注"如何填"，
因此 2 轮冒烟就收敛很快（roi_l1 0.255 → 0.186），60 轮后稳在 0.145。

## 4. 工程备注

- 训练过程中曾在 epoch 49 卡死（主进程用户态空转、GPU 0%、checkpoint 停写）。判据：
  **以 checkpoint 的 mtime 判断是否真卡死**，而非日志（stdout 块缓冲会滞后）。
  用 `last.ckpt` 断点续训从显示第 49 轮恢复，未损失训练进度。
- 可视化曾出现"后三格全黑"：真值传的是**亮温**、其余传的是**归一化值**，却统一做了反归一化 →
  vmin/vmax 被放大到数千 K。已修复，且拉伸范围只在**未损坏像素**上取（排除哨兵 0 K）。

## 5. 局限性（重要）

1. **单 seed（s42）**：方向性结论（"U-Net 明显优于插值"）很稳健（t≈15.6、胜率 97–99%），
   但具体数值不宜过度解读。
2. **评估用的是"人工损伤"**：测试年干净帧 + 训练年掩码库合成的损坏，与真实缺测的形态分布
   可能有差异（真实 IR1 缺测 81% 贴边，而这里随机平移后位置分布更均匀）。
3. **像素级优于叠加 ≠ 下游回归一定更好**：本项目已有明确反例——`feather=3` 在像素 RMSE 与接缝
   指标上双赢，但下游强度回归反而更差（`docs/inpaint_improvement.md`）。**若要把 U-Net 用在
   强度回归的预处理上，必须重跑四臂实验做下游验证，不能直接外推本报告的结论。**
4. 计算成本：U-Net 推理需要 GPU，而 griddata 是纯 CPU；本报告只衡量**质量**，未做速度/复杂度对比。

## 7. 后续实验（2026-10-13，追加）

针对"训练掩码面积（5%~40%，中位 8.05%）比真实损坏帧（中位 3.17%）偏大"的错配，
我们按真实面积分布重采样掩码池并重训了一版 U-Net。结果是**否定的**：

- 像素级（真实分布掩码池 N=600）：旧 **6.591** vs 新 **6.752** K（新差 +0.16 K，p=2.5e−25，
  7/7 面积档新都不如旧）；
- 下游（a3 臂，损坏帧 n=519）：旧 12.611 vs 新 12.603 kn（差 −0.008 kn，p=0.32）。

⇒ **匹配训练分布不是瓶颈**；决定泛化的是"训练难度/覆盖面"而非分布对齐。
**本报告的旧权重（`outputs/tcir_inpaint_unet/checkpoints/best.ckpt`）仍是 U-Net 首选**。
详见 `docs/unet_areamatch_report.md`。
