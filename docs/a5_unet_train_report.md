# a5 臂：把 U-Net 修复做进训练管线 —— U-Net 修复输入 vs 插值修正

> 实验日期：2026-10-13
> 动机：项目主线转为「**损坏图像修复 → 强度识别**」，此前所有 U-Net 对比都是**推理级**
> （在 a3 模型上换输入），从未把 U-Net 修复**用于训练**。本次补上这一环：
> 新增 **a5 臂 = 「训练与测试的输入都是离线 U-Net 修复后的 IR1」**，与既有四臂同口径对比。

## 1. 设置（与四臂严格同口径，唯一变量 = IR1 输入从哪来）

| 项 | 取值 |
|---|---|
| 通道 / 骨干 | IR1 单通道 / vgg16 |
| 划分 | by_year：训练 2003–2013（15952 帧）/ 测试 2014–2016（4107 帧，20.5%） |
| 验证集 | 无（`split=[0.8,0,0.2]`，best = 最后一轮） |
| 超参 | 80 轮、bs64、AdamW、lr 5e-4、grad_clip 1.0、AMP、seed 42（单次） |
| 测试 | 全集（damage_filter 全关），五臂同一测试集、逐帧配对 |
| a5 的修复来源 | `outputs/tcir_inpaint_unet_areamatch/checkpoints/best.ckpt`（新 U-Net，best_roi 0.1450） |

**a5 与 a2 的关键区别**：a2 用 griddata 插值修复（每帧现算），a5 用 U-Net 学习式修复且**离线预生成**；
两者都把「修复」放在**训练与测试的输入侧**，因此是真正的"臂级"对比（不像 `a3_repair_compare`
那样只在冻结模型上换输入）。

## 2. 管线改造：离线预修复 + 数据管线注入

U-Net 推理不能放进 DataLoader 多进程（worker 里跑 GPU 不安全），故改为**一次性离线修复 + 缓存**：

- 新增 `scripts/build_unet_repaired_ir1.py`：扫全量 20059 帧 IR1，检测缺测（哨兵 0 + 物理下界 150 K，
  min_blob 20，dilate 1 —— 与全项目一致），命中 **3969 帧（19.79%）**，用新 U-Net 修复后落盘
  `data/ir1_unet_repaired.npy`（146 MB, (K,96,96) 亮温域）+ `_idx.npy`（对应 h5 行号）。
  耗时 9.7 s。修复值域 150.9–312.0 K（物理合理）。
- `tcintens/data/tcir.py` 新增 `data.tcir.ir1_repaired_path`：`__getitem__` 中命中缓存的帧，
  其 IR1 通道**整帧替换**为修复值；**干净帧不在缓存里 ⇒ 输入零扰动**。
- `tcintens/utils/repro.py` 把该键纳入一致性守卫 ⇒ **评估自动对齐训练口径**，不会静默错配
  （实测 eval 日志：`data.tcir.ir1_repaired_path -> data/ir1_unet_repaired.npy`）。
- `scripts/run_ir1_arms.py` 新增 a5 臂；`scripts/ir1_arms_eval.py` 扩成五臂；
  新增 `scripts/arms_paired_analysis.py`（逐样本配对检验 + 面积分档）。

## 3. 结果

### 3.1 总表（测试全集 4107 帧）

| 臂 | 方案 | RMSE | MAE | R² | 偏置 |
|---|---|---|---|---|---|
| a1 | 无修正 | 12.714 | 9.475 | 0.8591 | −2.13 |
| a2 | 带修正 (griddata) | 12.521 | 9.474 | 0.8633 | −1.85 |
| a3 | 仅干净图训练 | 13.272 | 9.738 | 0.8464 | −2.42 |
| a4 | 无修正 + 条状增广 | 12.657 | 9.530 | 0.8603 | −1.78 |
| **a5** | **U-Net 修复输入** | **12.466** | **9.387** | **0.8645** | −1.72 |

> a1–a4 的数字与 `docs/ir1_year_arms_report.md` 完全一致 ⇒ 改造未引入任何偏差，可直接对比。

### 3.2 分组表（按「原始 IR1 是否缺测」）

| 臂 | 干净帧 RMSE (n=3588) | 损坏帧 RMSE (n=519) | 损坏帧偏置 |
|---|---|---|---|
| a1 无修正 | 12.596 | 13.499 | −1.270 |
| a2 带修正 | 12.490 | 12.731 | **−0.111** |
| a3 仅干净图 | 12.628 | **17.075** | −2.960 |
| a4 条状增广 | 12.639 | 12.780 | +0.180 |
| **a5 U-Net** | **12.438** | **12.654** | −0.366 |

### 3.3 损坏帧配对检验（n=519，|误差| 配对 t）

| 对比 | |误差| 均值差 | t | p | 胜率 |
|---|---|---|---|---|
| a5 vs a2 | −0.058 kn | −0.23 | 0.815 | 50.5% |
| a5 vs a1 | −0.263 kn | −0.84 | 0.401 | 49.5% |
| a2 vs a1 | −0.205 kn | −0.71 | 0.479 | 52.4% |

**三个对比全部不显著**——与既有结论一脉相承：修复方式带来的改善在 RMSE 上看得见，
但在逐样本 |误差| 分布上被少数极端样本主导（重尾），配对检验分辨不出。

### 3.4 损坏帧按缺测面积分档 RMSE

| 面积档 | n | a1 | a2 | a5 |
|---|---|---|---|---|
| <1% | 56 | 13.546 | **13.414** | 13.545 |
| 1–2% | 109 | 12.654 | 12.709 | **11.850** |
| 2–4% | 165 | 12.552 | **11.864** | 12.119 |
| 4–8% | 133 | 14.552 | **13.435** | 13.692 |

a5 在 1–2% 与 >8% 档最好，a2 在 2–4% 与 4–8% 档最好——**没有一致的档位优势**，
进一步印证"两者在下游基本等价"。

## 4. 结论

1. **a5（U-Net 修复输入）在全集/干净/损坏三个口径上都是五臂最优**（12.466 / 12.438 / 12.654），
   相对 a2 的收益约 **0.05–0.08 kn**（0.4–0.6%），且**不显著**（p=0.82）。
2. **"修不修"仍是决定性因素，与"用什么修"无关**：a1→a5 损坏帧 13.499→12.654（−0.85 kn），
   量级远大于 a5 vs a2（−0.08）。
3. **a5 连干净帧也最好**（12.438 vs a2 12.490）。干净帧三臂输入完全相同 ⇒ 差异只能来自
   **训练集分布**：a5 训练集里损坏帧被修复得更接近真实干净图，模型学到更一致的特征。效应同样很小。
4. **a5 的损坏帧偏置（−0.366）反而不如 a2（−0.111）**：U-Net 修复后模型仍略低估损坏帧。
5. **与推理级结论一致**：`docs/a3_repair_compare.md`（a3 模型下 U-Net vs griddata，p=0.34）与本实验
   （训练级，p=0.82）都指向同一结论 —— **U-Net 的像素级优势（缺测区 RMSE −20%）不会传导到下游强度回归**。

## 5. 实用建议

- **要上生产，`griddata` 仍是默认**：零成本、无模型依赖、无需预生成缓存，下游与 U-Net 等价。
- **U-Net 的唯一实用场景是"大面积损坏"**（>8% 档 a5 有 0.6 kn 优势），可按检测到的缺测面积触发。
- **想真正挖出 U-Net 的价值，杠杆不在"修得更准"**，而在别处（训练分布、多通道、时序上下文）。

## 7. 注意事项

- **单 seed（42）**。a5 与 a2 的 0.05–0.08 kn 差距远小于 seed 噪声，**不可据此断言 U-Net 更优**。
- a5 用的**新 U-Net（areamatch 版）**；`docs/a3_repair_compare.md` 的 unet 变体用的是**旧 U-Net**，
  但两者下游等价（见 `docs/unet_areamatch_report.md`），不影响本结论。
- 修复缓存只覆盖**全量 h5 中真实检测到的缺测帧**；`damage_filter` 关闭（测全集），
  故 a5 的测试集与四臂完全相同（4107 帧）。
